# Deadly Monsters 1.12.2 → 26.2 原生移植技术说明

本文件详细记录将 Deadly Monsters 从旧版 Minecraft Forge 1.12.2 原生重写并迁移至现代 Minecraft 26.2 (NeoForge / Fabric) 的核心架构决策与机制替代方案。

关联文档：[实机测试清单](测试清单.md) · [配方与显示兼容性](兼容性.md) · [返回主页](../README.md)

---

## 一、移植基线与设计原则

### 1. 目标工具链

* **Minecraft 目标版本**：26.2
* **NeoForge 版本**：26.2.0.75
* **Fabric Loader 版本**：0.19.5（配合 Fabric API 0.159.0+26.2）
* **开发构建工具**：Gradle 9.2.1 / ModDevGradle 2.0.146
* **运行时环境**：Java 25

### 2. 核心架构原则

* **原生重构而非兼容垫片**：本分支面向现代 Minecraft 架构进行彻底的原生重写，坚决不引入过时的旧 Forge 兼容层。
* **玩法身份完全保全**：所有方块、物品、实体及声音资源严格延续 `dmonsters` 命名空间与原始注册 ID，确保整合包历史迁移的一致性。
* **现代数据驱动落地**：全面遵循 26.2 数据驱动标准，配方、战利品表、BlockState、物品定义（Item Definition）及生物群系注入均采用规范 JSON 格式。

## 二、关键机制现代化演进

### 1. 世界时钟处理

* **旧版实现 (1.12.2)**：依靠硬编码的 `dayLengthTicks` 整数配置，通过直接修改世界时间数值实现昼夜切换。
* **现代移植 (26.2)**：Minecraft 26.2 引入了数据驱动的世界时钟与时间线体系。移植版废除了旧版整数配置，Sunlight Drop 与附魔牛（Haunted Cow）统一挂接当前主世界的昼夜标记进行状态流转。

### 2. 高频水下索敌性能治理

* **旧版缺陷 (1.12.2)**：水鬼（Topielec）的原版寻敌算法存在计时器边界缺陷，导致在潜水追踪时几乎每个 Tick 都在执行大范围全图水深搜索，造成显著的卡顿毛刺（Tick Spike）。
* **现代移植 (26.2)**：在完整保留水鬼将周围玩家拖入更深水域等标志性玩法的前提下，对索敌计算施加了合理的节流限频，彻底根除高成本循环。

### 3. 方块交互与安全权限

* **旧版缺陷 (1.12.2)**：钢筋（Rebar）对强化方块的加固与剥离直接修改世界方块，容易被利用绕过服务器领地保护。
* **现代移植 (26.2)**：所有触碰或修改方块的功能性物品均前置接入了现代世界的玩家交互事件与权限检查，杜绝越权破坏。

### 4. 自然生成机制演进

* **现代机制 (26.2)**：全面采用 NeoForge 的 Biome Modifier 机制进行生物群系生成规则注入。
* **配置联动**：每种怪物的生成权重（`spawnRate`）与开关（`disabled`）均在服务启动与群系数据构建时生效。

### 5. 旧版元数据（Metadata）平移

* 1.12.2 时代依靠元数据（Damage / Metadata）区分的各类方块与物品（如不同颜色的玻璃、鱼类产物、黏土及染料），全面映射为 Minecraft 26.2 的独立物品与方块注册项。
* 鱼叉（Harpoon）在水中使用成功捕获时稳定掉落鳕鱼（Cod），准确还原了 1.12.2 原版由于代码遗漏而呈现出的实际可见行为。
